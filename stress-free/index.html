About

메가 클릭 챌린지는 SKKU 2026년 도전학기 팀 프로젝트(팀 145)로 만든 미니 게임형 웹 서비스입니다. 큰 버튼을 누르면 이펙트가 터지고, 오늘 하루 모두가 함께 누른 클릭 수를 100만 클릭 목표로 채워갑니다.

제작 과정

  1. 각자 강의에서 다룬 VS Code + Claude Code 환경을 구축해 디자인 가이드(design.md)를 적용한 index.html을 5명이 각자 제작
  2. 5개의 샘플 중 팀 투표로 최종 결과물 1개 선정
  3. 이후 역할을 나누어 배포, DB·애널리틱스·SEO 세팅, 발표자료 제작, 영상 녹화까지 진행

만든이

  • 이윤우 — GitHub 업로드 · Vercel 호스팅(서비스 주소 생성) · 2차 구현
  • 박서현 — Supabase · Google Analytics 세팅, Google Search Console 등록(SEO 노출), 팀원 전체 사용 유도(DB 적재 · 통계 확보)
  • 장윤지 — 전 과정 PPT 제작, 영상 녹화용 스크립트 작성
  • 성현중 — PPT 기반 영상 녹화 — 서비스 데모 + Google Analytics 결과 포함 (5분 영상)
  • 문영호 (팀장) — 기말과제 총괄 기획 · 팀 운영/일정관리 · 1차 구현 · 과제 제출 · 교수님/조교님 소통 · 팀원 의견 조율
